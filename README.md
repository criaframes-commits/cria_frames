# Cria Frames

Site institucional da Cria Frames AI Studio, desenvolvido com Next.js, React,
TypeScript e Tailwind CSS.

## Desenvolvimento

Instale as dependências e inicie o servidor local:

```bash
npm install
npm run dev
```

O site estará disponível em [http://localhost:3000](http://localhost:3000).

## Verificações

```bash
npm run lint
npm run build
```

## Estrutura

- `app/`: rotas e layout global.
- `components/`: componentes de interface e seções das páginas.
- `docs/`: design system, style tile e wireframes.
- `styles/`: tokens de design.
- `public/`: posters, teaser otimizado e demais arquivos públicos.

O reel completo é reproduzido por um vídeo não listado do YouTube. O hero usa
um teaser curto, silencioso e otimizado para carregamento na web.
